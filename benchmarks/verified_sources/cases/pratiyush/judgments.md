Relevance uses the benchmark scale: 3 is direct/decisive evidence, 2 is useful supporting evidence, 1 is weak orientation, and 0 is a judged non-answer.

## Native and generic-shadow qrels

`queries.jsonl` and `qrels.jsonl` measure the native Pratiyush projection, including authored hubs such as `index`, `overview`, `CRITICAL_FACTS`, and folder `_context` pages. `queries-shadow.jsonl` and `qrels-shadow.jsonl` model the same source as a generic Markdown folder after authored hubs are removed from positive judgment credit. After the independent audit cleanup, the native set has 60 queries and 172 qrels; the shadow set has 55 queries and 144 qrels.

The shadow set keeps the 55 queries whose answerable positive qrels still have at least one relevance >=2 non-hub page, plus the five legitimate negative queries. It removes five native-only hub questions and removes every positive qrel to `index`, `overview`, `CRITICAL_FACTS`, `categories/_context`, `comparisons/_context`, `concepts/_context`, `entities/_context`, `questions/_context`, `sources/_context`, and `syntheses/_context`.

## Duplication audit

Exact normalized duplicate query ids and duplicate query texts are absent within each JSONL file. The shadow file intentionally reuses the shared native query text for paired native-vs-generic comparison rather than adding paraphrase-only variants.

The audit reviewed two high-overlap native/shadow pairs. `q-pratiyush-citation-arc-agi-double-digits` is retained as a citation-class check for the GPT-5 benchmark metadata and the ARC-AGI-2 interpretation page, while `q-pratiyush-numeric-gpt5-arc` is retained as a numeric/literal retrieval check for the exact 16.4 percent claim. `q-pratiyush-multihop-claude-agentic-cost` is retained as the Claude/workload/cache economics triad, while `q-pratiyush-multihop-claude-anthropic-agent-cache` is retained as a provider-to-model-to-concept traversal that specifically requires the Anthropic provider page. These pairs intentionally share some qrels but are not paraphrase-only inflation.
